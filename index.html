01 — Sobre mí

Trabajo en la intersección donde el código se encuentra con los datos y con la seguridad.

Soy Irvin Gonzalez, desarrollador backend con enfoque en análisis de datos y ciberseguridad. Diseño APIs y arquitecturas de servidor pensadas para durar, extraigo valor de conjuntos de datos complejos y aplico una mentalidad de seguridad ofensiva y defensiva en cada capa del sistema.

Para mí, un buen sistema no es solo el que funciona hoy: es el que se puede auditar, escalar y defender mañana.
